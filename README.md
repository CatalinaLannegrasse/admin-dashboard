# Admin Dashboard — Arcane Edition

A custom-themed Admin Dashboard built as part of **The Odin Project** curriculum. This project showcases advanced CSS Grid and Flexbox layouts, structured HTML semantics, and a sleek, gritty dark-mode aesthetic inspired by *Arcane* (Zaun & Piltover).

## Features
* **Custom Layouts:** Built from scratch using multi-level CSS Grid and Flexbox containers.
* **Arcane Theme:** Styled with a Piltover/Zaun techno-punk palette, featuring dark blues, Hextech blue glows, and Jinx-inspired details.
* **Responsive Card Grid:** Project cards dynamically wrap and resize based on the viewport.
* **Structured Sections:** Includes a sticky sidebar navigation, detailed user header, project cards, announcements widget, and trending profiles.

## Built With
* Semantic HTML5
* CSS3 (Grid & Flexbox)
* Git & Version Control
